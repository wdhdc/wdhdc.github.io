 wdhdc 主页仓库 · videos 文件夹使用说明
================================================================

本文件夹存放主页「视频」板块的全部素材，由主页仓库根目录的
player.html 读取并播放。

▍目录结构
----------------------------------------------------------------
videos/
├── 需要什么文件.txt        ← 本说明文件
├── data.json               ← 视频总目录（播放器读取的唯一入口）
└── <每个视频一个文件夹>/    ← 命名建议：日期-短标题（全英文/数字/连字符）
    ├── info.json           ← 视频信息（必填）
    ├── video.mp4           ← 视频文件（必填）
    ├── cover.png           ← 封面图（选填，建议 1280×720）
    └── subtitle.srt        ← 字幕（选填）

▍添加一个视频（4 步）
----------------------------------------------------------------
① 在 videos/ 下新建一个文件夹，例如：2026-10-11-demo

② 把视频文件放进去。支持 .mp4 / .webm / .mov，
   GitHub 单文件上限 100MB，建议压缩到 50MB 以内的 H.264 MP4
   （浏览器兼容性最好，手机也能播）。

③ 在该文件夹里创建 info.json（模板见 videos/_template/info.json），
   字段说明如下：

   {
     "id":          "2026-10-11-demo",     // 必填 · 唯一ID（建议用文件夹名）
     "title":       "视频标题",             // 必填 · 标题
     "date":        "2026-10-11",          // 必填 · 日期（YYYY-MM-DD）
     "description": "一句话简介",            // 选填 · 简介
     "tags":        ["游戏", "教程"],       // 选填 · 标签（可多个）
     "duration":    "01:23",               // 选填 · 时长
     "cover":       "cover.png",           // 选填 · 封面文件名
     "file":        "video.mp4",           // 必填 · 视频文件名
     "featured":    false                  // 选填 · true=置顶推荐
   }

④ 编辑 videos/data.json，在 "videos" 数组里追加一条记录：
   { "folder": "2026-10-11-demo" }
   播放器会自动读取该文件夹下的 info.json。
   提交推送后，刷新播放器页面即可看到新视频。

▍播放器如何工作
----------------------------------------------------------------
- 播放器（player.html）先读取 videos/data.json 得到视频文件夹清单；
- 再逐个读取每个文件夹的 info.json，组装成播放列表；
- 视频和封面通过 GitHub raw 直接加载（支持拖动进度条），
  目录信息通过 jsDelivr CDN / GitHub API 加载；
- 推送后 jsDelivr 缓存约 1~2 分钟刷新，若看不到新视频请稍等后
  在地址栏加 ?v=时间戳 强制刷新。

▍注意事项
----------------------------------------------------------------
- 所有文件名避免中文和空格，用英文、数字、连字符，防止链接失效；
- 封面建议 1280×720（16:9），.png 或 .jpg；
- 视频太大传不上时，先用压缩工具处理（如 HandBrake / ffmpeg）：
    ffmpeg -i 原片.mp4 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 128k 输出.mp4
- 想删除视频：删除对应文件夹 + 移除 data.json 里的记录即可。
